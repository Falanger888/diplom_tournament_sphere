# Tournament Sphere 🛡️🐉

Официальное сообщество по организации киберспортивных турниров для игры **ArcheAge**. 
Проект представляет собой веб-платформу для регистрации игроков, поиска команд и участия в турнирах (1 VS 1, 2 VS 2, 5 VS 5).

> **Статус проекта:** Дипломный проект. 
> На данный момент проект переведен в режим **демонстрационного макета (UI/UX)**, так как боевая база данных была утеряна. Все данные (пользователи, турниры, команды) генерируются из файла `data.php` (моки). Архитектура полностью готова к подключению реальной БД (через PDO).

## 🚀 Основной функционал
*   **Турниры:** Выбор категории (1v1, 2v2, 5v5), выбор игрового сервера, регистрация участников.
*   **Турнирная сетка:** Визуализация плей-офф (Четвертьфиналы, Полуфиналы, Финал).
*   **Команды:** Создание команды, управление составом (для капитанов), система приглашений и заявок.
*   **Профили игроков:** Статистика игр, уведомления, управление персонажами (привязка к серверам и классам).
*   **Новости и Поддержка:** Лента новостей и форма обратной связи.

## 🛠 Технологии
*   **Backend:** PHP 8.3 (Чистая архитектура без фреймворков)
*   **Frontend:** HTML5, CSS3 (Glassmorphism, Flexbox, Grid), Vanilla JavaScript (ES6)
*   **Шаблонизация:** Разделение на `header.php` и `footer.php` для исключения дублирования кода.
